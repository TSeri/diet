# ダイエット記録アプリ

Diet用の健康ログアプリ。

体重・体脂肪率・測定日時・食事をオフラインで記録する、HTML1枚のアプリです。
サーバーもアカウントも不要で、データは **その端末のブラウザの中だけ** に保存されます（外部に一切送信しません）。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。これ1つで全機能が動きます |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン設定 |
| `sw.js` | オフラインキャッシュ（https で配信したときだけ有効） |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アイコン |

## できること

- **体組成**：測定日時・体重(kg)・体脂肪率(%)・メモ。あとから編集／削除できます
- **食事**：日時・区分（朝食/昼食/夕食/間食/飲み物）・内容・カロリー・たんぱく質・メモ
  - よく使う内容はボタンで一発入力（カロリーも自動で埋まります）
- **アルコール**：酒量(ml)と度数(%)から純アルコール量(g)を自動計算
  - ビール350/500ml・ハイボール・缶チューハイ・ワイン・日本酒1合・焼酎・ウイスキーのプリセット付き
  - 1日の上限を設定でき、超えた日はグラフで赤く表示。休肝日もカウントされます
- **生活記録**：起床・就寝・排便・排尿をワンタップで記録
  - 就寝と起床がそろうと睡眠時間を自動計算（日をまたいでも対応）
  - 排便はブリストル便形状スケール7段階で状態を残せます
  - 時刻を指定したり、あとから修正することもできます
- **記録の修正**：履歴タブで記録をタップすると入力欄に読み込まれ、日時を含めて修正できます（🗑 で削除）
- **サマリー**：最新体重、前回比、7日平均と週あたりの増減、BMI、目標までの残り、今日の摂取カロリー
- **グラフ**：体重＋体脂肪率の折れ線（7日移動平均・目標体重ライン付き）、1日の摂取カロリー・睡眠時間・純アルコール量の棒グラフ。期間は 1週間／1ヶ月／3ヶ月／半年／全期間
- **履歴**：日付ごとにまとめて表示。その日の体重と合計カロリーも並びます
- **設定**：身長・目標体重・1日の目標カロリー／たんぱく質・1日の純アルコール上限
- **書き出し**：JSON（バックアップ用・アプリに読み戻せる）と CSV（Excel/Numbers用）。iPhoneでは「共有」ボタンからiOSの共有シートに直接渡せます
- ダークモード自動対応

## 使い方（PC）

`index.html` をダブルクリックするだけです。ブラウザで開けばそのまま使えます（ネット接続不要）。

## 使い方（iPhone）

### おすすめ：https のどこかに置いて「ホーム画面に追加」

このフォルダごと GitHub Pages などの静的ホスティングに置き、iPhone の Safari でそのURLを開いて
「共有 → ホーム画面に追加」。以降はアイコンから起動でき、**機内モードでも動きます**（`sw.js` がキャッシュします）。
記録したデータはiPhoneの中だけに残ります。

### Mac のサーバー経由で使う（同じWi-Fi内）

このフォルダで:

```bash
python3 -m http.server 8811
```

iPhone の Safari で `http://<Macのローカルアドレス>:8811/` を開きます。アドレスはMacで:

```bash
ipconfig getifaddr en0
```

※ この方法（http）だとブラウザの制約で `sw.js` が動かないため、**オフライン化はされません**（Macのサーバーが必要です）。
常時オフラインで使いたい場合は上の https 方式にしてください。

## 書き出し（設定タブ → データ管理）

| 形式 | 用途 | 読み戻し |
|---|---|---|
| JSON | バックアップ・機種変更 | できます（追加／置き換え） |
| CSV | Excel・Numbers で集計やグラフ | できません（書き出し専用） |

それぞれ **保存**（ファイルとしてダウンロード）と **共有**（iOSの共有シートを開き、ファイルApp・メール・LINEなどに直接送る）が選べます。
「共有」は対応している端末でのみ表示されます（iPhone/iPad、Androidなど）。PCでは「保存」だけが出ます。

CSVは14列（種別・日時・体重kg・体脂肪率%・区分・内容・kcal・たんぱく質g・酒量ml・度数%・純アルコールg・便の状態・睡眠時間h・メモ）で、体組成・食事・生活記録が新しい順に並びます。
「種別」列が 体組成 / 食事 / 生活 の3値なので、Excel側でフィルタすると目的の記録だけ取り出せます。
先頭にBOMを付けているので、Excelでダブルクリックしても文字化けしません。

```
種別,日時,体重kg,体脂肪率%,区分,内容,kcal,たんぱく質g,酒量ml,度数%,純アルコールg,便の状態,睡眠時間h,メモ
体組成,2026/8/25 7:10:00,68.6,24.3,,,,,,,,,,起床後
食事,2026/8/25 19:30:00,,,夕食,鮭の塩焼き・味噌汁・野菜,665,38,,,,,,
食事,2026/8/25 20:00:00,,,飲み物,ビール500ml,200,,500,5,20,,,
生活,2026/8/25 6:20:00,,,起床,,,,,,,,7.17,よく眠れた
生活,2026/8/25 7:40:00,,,排便,,,,,,,4 普通便,,
```

## バージョンの確認

アプリの **設定タブ → バージョン** に、いま動いている版が出ます。

```
バージョン 1.3.0（2026-08-25）
オフライン対応：有効
```

iPhoneで更新が反映されたか確かめたいときはここを見てください。
**更新を確認** ボタンを押すと配信元に新しい版がないか問い合わせ、あれば取得して自動で再読み込みします（無ければ「すでに最新です」）。

「オフライン対応：有効」なら Service Worker が動いていて、機内モードでも起動します。
`index.html` をPCで直接開いた場合は「なし（ファイルを直接開いています）」になります。これは正常で、常に最新のファイルが読まれます。

## 更新をリリースするとき

`index.html` の `APP_VERSION` / `APP_BUILD` と、`sw.js` の `CACHE` を**同じバージョンに揃えて**から push してください。
`CACHE` の名前が変わることでブラウザが新しい Service Worker として認識し、端末側に更新が届きます。

```js
// index.html
var APP_VERSION = "1.3.0";
var APP_BUILD   = "2026-08-25";

// sw.js
var CACHE = "diet-tracker-1.3.0";
```

## データについて（大事）

- データはブラウザの localStorage に入ります。**Safariの「履歴とWebサイトデータを消去」やプライベートブラウズで消えます。**
- 機種変更・ブラウザ変更ではデータは引き継がれません。
- 定期的に `設定 → JSONで書き出し` でバックアップを取り、新しい端末では `JSONを読み込み` で戻してください。
